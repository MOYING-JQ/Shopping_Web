## 二、待修复问题清单（按优先级）

### 🔴 高优先级（安全 / 配置失效）

#### 问题 1：OrderMapper.xml 排序字段存在 SQL 注入风险



* **位置**：`src/main/resources/mapper/OrderMapper.xml`（`selectOrderPage`、`selectOrderPageBySell` 两处）

* **现状**：



```
\<choose>

&#x20;   \<when test="dto.sortField != null and dto.sortField != ''">\${dto.sortField} \${dto.sortOrder}\</when>

&#x20;   \<otherwise>o.create\_time DESC\</otherwise>

\</choose>
```

`${}` 直接拼接前端传值，攻击者可传 `sortField=id;DROP TABLE t_order` 之类的内容。



* **修改方案**：白名单映射，只允许指定字段和方向：



```
\<choose>

&#x20;   \<when test="dto.sortField == 'createTime'">o.create\_time\</when>

&#x20;   \<when test="dto.sortField == 'totalAmount'">o.total\_amount\</when>

&#x20;   \<when test="dto.sortField == 'status'">o.status\</when>

&#x20;   \<otherwise>o.create\_time\</otherwise>

\</choose>

\<choose>

&#x20;   \<when test="dto.sortOrder == 'asc'">ASC\</when>

&#x20;   \<otherwise>DESC\</otherwise>

\</choose>
```

### 🟡 中优先级（体验 / 代码质量）

#### 问题 3：时间格式未统一，前端显示 `2026-08-24T20:09:12`



* **原因**：`LocalDateTime` 默认按 ISO 序列化（带字母 T），页面观感差。

* **修改方案 A（推荐，全局配置）**：新增 `config/JacksonConfig.java`



```
package com.moying.project\_test.config;

import com.fasterxml.jackson.datatype.jsr310.deser.LocalDateTimeDeserializer;

import com.fasterxml.jackson.datatype.jsr310.ser.LocalDateTimeSerializer;

import org.springframework.boot.autoconfigure.jackson.Jackson2ObjectMapperBuilderCustomizer;

import org.springframework.context.annotation.Bean;

import org.springframework.context.annotation.Configuration;

import java.time.LocalDateTime;

import java.time.format.DateTimeFormatter;

@Configuration

public class JacksonConfig {

&#x20;   private static final DateTimeFormatter FORMATTER =

&#x20;           DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

&#x20;   @Bean

&#x20;   public Jackson2ObjectMapperBuilderCustomizer jacksonCustomizer() {

&#x20;       return builder -> {

&#x20;           builder.serializers(new LocalDateTimeSerializer(FORMATTER));

&#x20;           builder.deserializers(new LocalDateTimeDeserializer(FORMATTER));

&#x20;       };

&#x20;   }

}
```



* **修改方案 B**：也可以在 `application.yaml` 增加：



```
spring:

&#x20;   jackson:

&#x20;       time-zone: Asia/Shanghai

&#x20;       date-format: yyyy-MM-dd HH:mm:ss
```

> 注意：
>
> `date-format`
>
>  只对 
>
> `java.util.Date`
>
>  生效，
>
> `LocalDateTime`
>
>  必须用方案 A。

#### 问题 4：DashboardServiceImpl 重复代码 + 调试输出



* **位置**：`service/impl/DashboardServiceImpl.java`

* **现状**：`getTotal()`、`getTrend()`、`fandStatus()` 三个方法重复 "JWT 取用户名 → 查 User → 取 id"，且使用 `System.out.println` 打印。

* **修改方案**：抽取私有方法：



```
private User getCurrentUser() {

&#x20;   QueryWrapper\<User> queryWrapper = new QueryWrapper<>();

&#x20;   queryWrapper.eq("username", fromJwt.username());

&#x20;   User user = userMapper.selectOne(queryWrapper);

&#x20;   if (user == null) {

&#x20;       throw new BusinessException("请登录");

&#x20;   }

&#x20;   return user;

}
```

三个方法改为：



```
Long id = getCurrentUser().getId();
```

打印语句替换为日志：



```
import lombok.extern.slf4j.Slf4j;

// 类上加 @Slf4j，打印改：

log.info("最近7天销售数据：{}", salesTrendVos);
```

#### 问题 9：SecurityConfig 注释过时



* **现状**：注释写 "现阶段全部接口放行"，但实际已配置白名单 + 其余鉴权。

* **建议**：更新注释为真实逻辑，避免误导：



```
// 白名单（登录注册、商品浏览、分类、静态图片）放行，其余接口需 JWT 认证
```

#### 问题 10：selectMaps 结果强转 Long 的隐患



* **位置**：`DashboardServiceImpl.getTotal()`



```
Long totalOrders = (Long) resultMap.get("totalCount");
```



* **建议**：COUNT 在 MySQL JDBC 通常返回 Long，多数情况正常；稳妥写法：



```
Long totalOrders = Long.parseLong(resultMap.get("totalCount").toString());
```
